# Teknik envanteri (kanal başına)

Her dosya bir kanalın en popüler videosundan çıkarılan edit teknikleridir: eksen, yeniden yapım tarifi, kanıt (zaman damgası),
repertuarda karşılığı (`repertuarda`), etiket önerisi, öncelik (1–3). Kaynak profil: Drive `edit kutuphane/kanallar/@X/EDIT-DILI.md`.

- `repertuarda: null` ve `oncelik >= 2` olanlar kodlanacak adaylardır. 2026-11-24'te kodlananlar `etiketler.json`'da `kaynak` alanında kanal adıyla görünür.
- Henüz kodlanmayanlar (sonraki tur): 3D kesit sondaj inişi, ölçek karşılaştırma silüeti, el yazısı kinetik etiket, çizgi film anlatıcı karakter,
  parşömen rulo kartı, piksel karakter, 2D vektör animasyon sahnesi, el feneri ışık konisi, nesne spot izolasyonu.
